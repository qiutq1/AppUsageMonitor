# 应用使用时长

一个独立的 Android 应用，用于按日期范围查看选定应用的前台使用时长、打开次数和每次打开/关闭时间，并导出 CSV 表格。

## 使用方式

1. 用 Android Studio 打开本目录并同步 Gradle。
2. 在手机上安装并启动应用。
3. 点击“前往系统设置”，为“应用使用时长”开启使用情况访问权限，然后返回应用。
4. 点击日期范围可以选择开始和结束日期（包含首尾两天），例如查看 9 月 1 日至 9 月 10 日的使用情况。
5. 在“管理应用”中按首字母混合排序浏览应用（中文按拼音首字母），也可以搜索中文名、英文名或拼音；勾选需要监控的应用，或使用全选/取消全选。选择会保存在本机。
6. 点击汇总中的应用名称，可以查看该应用每次打开和关闭的具体时间。
7. 首页汇总可以切换按使用时长或应用名排序；滚动列表时，当前所在的“使用汇总”或“打开记录”标题会吸顶显示。
8. 点击“导出 CSV”，在系统文件选择器中选择保存位置。

数据由 Android `UsageStatsManager` 提供。系统权限开启之前不会有历史记录；统计按本地自然日计算。CSV 使用 UTF-8 编码，每次打开一行，包含应用名称、包名、打开时间、结束时间和使用时长（毫秒），可用表格软件打开。

项目使用 Android Gradle Plugin 8.8、Gradle 9.6 和 Android SDK 35。
